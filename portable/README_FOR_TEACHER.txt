Mentis ClassWiz calculator: how to run

For the v0.12 GitHub ZIP:
1. Download and extract the complete ZIP. Do not run the calculator from inside the ZIP.
2. Open the extracted folder, then open its portable folder.
3. Double-click RUN_CALCULATOR.bat. Your browser opens the calculator.
4. This source ZIP does not include the generated Python runtime. It uses a bundled
   Python runtime when one is present; otherwise, it requires Python 3 on PATH.
5. To stop the calculator, close the black console window.
6. It works locally and does not need internet after it has been extracted.

For the complete portable folder supplied on a USB stick:
1. Copy the whole calculator_portable folder to the Desktop. Do not run it from a ZIP.
2. Open the folder and double-click RUN_CALCULATOR.bat. It uses its bundled Python.
3. If Windows shows a SmartScreen box, click "More info", then "Run anyway".
4. If a firewall box appears, choose "Allow". The server listens only on this computer.
5. Close the black console window to stop the calculator.

If something goes wrong, send Zaidi the launcher log from the portable folder.
